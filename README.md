# HealthOps FHIR Canada

HealthOps FHIR Canada is an end-to-end healthcare data quality and implementation platform that ingests synthetic HL7 FHIR records, validates healthcare data, stores normalized information in PostgreSQL, exposes operational metrics through a REST API, and presents implementation and data-quality indicators in Power BI.

## Business Purpose

The project simulates a Canadian health technology company receiving clinical data from multiple healthcare organizations. It demonstrates how healthcare data can be ingested, validated, transformed, investigated, tested, and monitored.

## Current Status

The project is currently in the initial planning and environment setup stage.

## Planned Capabilities

- Synthetic FHIR R4 data ingestion
- Healthcare data-quality validation
- Relational storage in PostgreSQL
- Operational REST API using FastAPI
- Automated testing with pytest
- API testing using Postman
- Operational reporting with Power BI
- Implementation and support documentation

## Data Privacy

> This portfolio project uses synthetic patient data generated for educational and demonstration purposes. It does not contain real protected health information.

## Limitations

This project is an educational portfolio prototype. It is not a production clinical system and must not be used to process real patient information.
